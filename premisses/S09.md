## Chez Lordon

Démonstration de III, 37, citée quatre fois : comme tout affect triste, la crainte induit du conatus un surplus d'activité pour s'en défaire (11.1, note 25 ; T012) ; la tristesse du travail sans sens peut pousser à la rébellion (22.8, note 64 ; T026) ; le salarié réjoui par l'amour du maître désire conserver cette joie (23.3, note 71 ; T027) ; la tristesse commune née d'une offense fait la puissance de l'indignation (38.4, note 129 ; T042).
